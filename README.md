# NutriScan-AI

An AI-powered food calorie and nutrition analyzer built using Python, Streamlit, and Google Gemini.

## 📌 Project Overview

NutriScan-AI analyzes an uploaded food image and uses Google's Gemini AI model to identify the food items and estimate their calorie content.

The application provides a simple and interactive interface where users can upload a food image and receive an AI-generated calorie analysis.

## 🚀 Features

- Upload food images
- AI-based food identification
- Calorie estimation for detected food items
- Total calorie calculation
- Simple Streamlit web interface
- Powered by Google Gemini AI

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Google Gemini API**
- **Google GenAI Python SDK**
- **Pillow (PIL)**
- **python-dotenv**
